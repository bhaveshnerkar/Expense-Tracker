# Python Expense Tracker

A beginner-friendly Python command-line application for recording expenses and calculating total spending.

## Features

- Add expenses with a name and amount
- View all recorded expenses
- Calculate total expenses
- Validate empty expense names
- Reject invalid and non-positive amounts
- Handle empty expense lists
- Simple menu-driven interface

## Technologies Used

- Python 3
- Git and GitHub
- GitHub Codespaces

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python main.py
   ```

## How to Use

1. Choose `1` to add an expense.
2. Choose `2` to view recorded expenses.
3. Choose `3` to calculate total spending.
4. Choose `4` to exit the application.

## Example

```text
1. Add Expense
2. View Expenses
3. Calculate Total
4. Exit

Total: 80 Rs.
```
